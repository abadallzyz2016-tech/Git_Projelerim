# Average Calculation App

Bu proje, C# Console uygulaması olarak geliştirilmiş bir **ders ve dönem notu hesaplama sistemidir**.

## Özellikler

- Ders notlarını kullanıcıdan alır.
- Her ders için not ortalamasını hesaplar.
- Dönem genel not ortalamasını (GNO/DNO) hesaplar.
- Kullanıcı dostu konsol arayüzü sunar.
- Hatalı girişlere karşı temel kontroller içerir.

## Kullanılan Teknolojiler

- C#
- .NET Console Application

## Nasıl Çalıştırılır?

1. Projeyi klonlayın:

```bash
git clone <repo-linki>
```

2. Proje klasörüne girin:

```bash
cd AverageCalculationApp
```

3. Uygulamayı çalıştırın:

```bash
dotnet run
```

## Kullanım

Program çalıştırıldığında:

- Ders sayısı girilir.
- Her ders için not bilgileri alınır.
- Program ortalamaları hesaplar.
- Sonuçlar ekranda gösterilir.

## Örnek Çıktı

```text
Ders Sayısı: 3

1. Ders Notu: 85
2. Ders Notu: 70
3. Ders Notu: 95

Dönem Ortalaması: 83.33
```
